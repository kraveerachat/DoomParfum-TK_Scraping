# Security, reliability and acceptance
Trust boundaries: untrusted page DOM/URLs/recipe/model output; extension isolated world; paired local daemon; client MCP; isolated runner; external source; parent import. Loopback alone not authentication. Use scoped short-lived/revocable token and origin/Host checks, reject wildcard CORS, bind IPv4 loopback, request sizes and rate limits, protect against CSRF/DNS rebinding; authenticate each channel and validate tab origin on navigation. No broad host permissions: activeTab + optional approved hosts; no cookie permission, arbitrary script/eval or page input/password extraction. Model prompt injection: page text is data, no authority, no secrets in context, no tool calls without policy checks. Job limits enforced server-side; fail closed, no scope escalation.
Network policy: exact HTTPS origin allowlist including required approved assets; validate each redirect and request, resolve/check IP and reject loopback/private/link-local/metadata or disallowed schemes; enforce egress isolation where practical, DNS rebinding negative tests; fixture-only explicit separate local network policy. Block downloads except approved content types/sizes, sanitize filenames; no arbitrary output path, no traversal/symlink escape. Data table text rendering no innerHTML on untrusted data; CSV formula neutralization, Unicode/newline quoting; no raw session logging. Local storage retention and delete controls, backups and atomic export. Separate dedicated runner profile. No stealth/proxy evasion.
Testing: unit candidate group detection, selector escaping, relative scope, JSON schema, numeric/raw parsing, dedup, state transitions and CSV; integration API auth, policy, DB restart, lease, cancel, timeout, export; E2E extension load in Chromium then real Brave/Chrome on Windows, 20 synthetic cards + distractor, missing fields, multiple detail sections, table, next-page/load-more/scroll cycles, list-to-detail; MCP both clients; local model malformed/injection/timeout; negative controls cross-origin redirect, private address, unpaired extension, invalid grant, expired token, XSS/CSV, path escape, limits, non-authorized domains incl. Fragrantica without contacting them. CI tests local only and no secrets. Synthetic expected output compared exact; performance benchmark 100/1000 fictional rows, report measured time and memory, no invented thresholds/results. Runtime tests NOT RUN.
