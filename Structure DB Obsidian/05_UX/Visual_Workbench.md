# UI and interaction specification
Reference: Owner-provided screenshots show Ultimate Web Scraper sidebar tools, List Extractor, group outline with item count, Load More options, separate data table window, and perfume detail sections. Recreate interaction concepts only, original brand/design.
## Screens
- Home: Tk logo, status local/connected, Tools, Recipes, Data, Jobs, Settings. List Extractor and Detail Extractor primary; Page Text and Image assets later; other tools deferred. No Cloud tab dependency.
- List picker: start -> pointer hover with outer solid outline and repeating child outlines -> show count, confidence, candidate groups -> click locks group -> select/suggest fields -> preview -> choose load strategy -> run -> data view. Esc cancels; overlay pointer-events none; intercept click only in selection mode; cleanup on navigation/tab close; keyboard support. Parent/child cycling; exclude unrelated cards; undo/redo. Scope group so sidebar/recommendations are excluded.
- Detail picker: select page type, then multiple independent sections; add scalar, object or list. Example synthetic perfume hero title/brand/image, accords, user-rating panel, season/day-night panel, pyramid Top/Middle/Base. Each section has label/type, selected elements, preview, required/optional, missing warning. User or agent can add fields and validate; no forced single record box.
- Data table: separate extension page via new tab/window, list dataset and row count, source and job metadata, search/filter/sort, column rename, drill down nested JSON arrays, image URL preview only if approved, CSV/JSON export, delete local dataset confirmation. Display actual row count vs candidates; never imply extraction succeeded if missing.
- Recipes: version, source permission, page-type, test results, edit/clone/import/export, approval state, dry-run.
- Jobs: queued/running/paused/completed/partial/failed/cancelled, rows/pages, current URL sanitized, errors, stop/resume where safe.
- Agent mode: show current tab lease, proposed selection overlays and schema diff, approval prompts for scope change; disconnect/revoke and stop. Agent uses semantic tool actions rather than physical mouse movements; optional visible highlight. No simulated click on arbitrary page controls.
- Settings: local pairing, model endpoint/name, model capability check, budgets, storage/export, source policy, no credentials in UI logs.
Accessibility: keyboard picker controls, labels, focus restoration, reduced motion, readable contrast. Screenshots in public repo only synthetic. Acceptance: user can complete list and multi-section detail workflows without agent; AI-off remains usable.
