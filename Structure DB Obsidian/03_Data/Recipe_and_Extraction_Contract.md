# Recipe and extraction contract v0.1 (proposed)
Recipe = schemaVersion, recipeId, revision, sourceId, allowedOrigins, pageType, startURLs (approved scope only), recordGroup (optional for singleton), fields tree, navigation edges, limits, provenance policy, validation tests. Field = key, selector alternatives, scope, extraction enum(text, attribute from allowlist, url, number, list, object), cardinality(1/optional/many), expected type, transform enum, evidence capture flag. No arbitrary JS in imported recipes. Validate all lengths, URLs, selectors, field nesting and limits before execution. JSON canonical; CSV flatten arrays as JSON cells or separate child tables; never zip arrays by index across independent groups.
## Detection
Collect candidate ancestors of hovered element; compare sibling structural signatures (tag, stable attribute, child pattern), density and similarity; prefer record group with coverage and minimal unrelated matches. Field suggestions from repeated child shapes and semantics; confidence, sample null rate and match count; fallback manual. Prefer stable attributes and relative selectors; avoid dynamic classes and nth-child unless explicitly confirmed. Check candidate selectors against multiple synthetic pages, handle missing/duplicate matches and report drift. Scope extraction relative to record/section; independent singleton sections and nested arrays. Normalize links against page URL; images currentSrc only when allowed; preserve raw string + parsed value, not invent.
## Navigation and execution
Recipe DAG: list -> optional detail URLs from approved field -> detail extractor; optional next-button, load-more, bounded scroll; stop on no new stable keys, repeated page/cycle, disabled control, limit, timeout, permission failure or challenge. Conservative default 1 worker, 3 pages, 50 records, 60 seconds on pilot; source-specific lower limits override; backoff on permitted transient errors only; stop on 401/403/429/challenge. Dedup canonical source key; checkpoint job and page with idempotent writes. Never silently switch origin, expand scope or click unrelated controls. Virtualized lists and iframe/shadow support deferred.
## Data envelopes
Job states queued, running, paused, succeeded, partial, failed, cancelled; explicit terminal reason. Result envelope schemaVersion, jobId, recipe revision, sourceId, acquiredAt UTC, items, warnings, counts, validation report. Every field carries source URL (sanitized), observed timestamp, extraction rule version, raw value where permitted, missing/ambiguous status, rights reference; source facts and AI suggestions separate. Preview bounded (10 rows, 64 KiB proposed); full datasets on local disk, not model context. Stable record keys, hashes for exports and manifest. No hidden fields, tokens, raw HTML or forms by default.
