# DoomParfum TK Scraping | Tk-Web-Scraper
Local-first visual and agent-assisted extraction toolkit for DoomParfum By TK. Independent repository; manual operation remains useful without AI. Windows, Brave and Chrome first. No required paid scraping service.
**Status:** PROPOSED / planning only. No runtime, verified extraction, deployment or source permission exists.
Start at [Obsidian index](Structure%20DB%20Obsidian/00_Home/Project_Index.md), [workflow](DEVELOPMENT_WORKFLOW.md), [agent rules](AGENTS.md).
Parent repository: https://github.com/kraveerachat/DoomParfum-By-TK (read-only for this initiative). Exchange reviewed, versioned datasets, never write parent DB directly.
Initial plan TKS-PLAN-001 requires Owner merge. Fragrantica is a reference for desired data shape only: automated access and reuse remain blocked absent written permission. See source registry.
